# Presentation Copilot

Presentation Copilot 可以将用户的想法整理成演示文稿大纲和页面描述，生成幻灯片图片，再导出 PPTX 或 PDF。

- 在线应用：[slides.scylab.top](https://slides.scylab.top/)
- 历史 RC05 源码：[发行说明](https://github.com/cy180-cy/presentation-copilot/releases/tag/rc-20261116-05) · [完整源码 ZIP](https://github.com/cy180-cy/presentation-copilot/releases/download/rc-20261116-05/presentation-copilot-rc-20261116-05-source.zip)

源码包内附 `docs/SOURCE_OFFER.md`、构建和运行说明、许可证及第三方声明。
